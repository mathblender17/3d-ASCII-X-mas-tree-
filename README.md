# 3D ASCII Indian Christmas Tree

A spinning Christmas tree drawn entirely in text characters, with an Indian touch: marigold garlands, diyas, a rangoli floor, saffron star lanterns and a Marathi greeting.

Everything lives in one file, `index.html`. No build, no dependencies.

## Use it

Open the page (locally or on GitHub Pages) in Chrome.

- **Mode**: *Making-of* types the code while the tree builds; *Final tree* shows the finished tree.
- **Song**: optionally pick your own audio file and a start second. Without one, the video is silent.
- **Preview**: plays the 24 s reel.
- **Record reel & download**: saves a 1080×1920 video (MP4 in Chrome, otherwise WebM) ready for Instagram Reels.

## Pages

- `index.html` — the Christmas tree.
- `diwali.html` — the same 3D tree dressed for Diwali: diyas, marigold petals, gold and magenta lights, and a Marathi greeting.
